# 号枢

中文名：**号枢** · 前缀 `haoshu` · 端口 **6300 / 11300**

## 骨架

**业务键入枢纽 → 关系进链接 → 属性进卫星（载荷哈希开版）→ 枢纽-链接-卫星互证**

皮：号卡 / 套餐 / 客户。去皮是 Data Vault，不是营业厅办号、不是积分商城。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6300 → 入湖灌样例 → 枢纽/链接/卫星 → 贯验
```

## 套餐下架断链（已落地，口径甲：仅挡新链）

全局唯一口径：**停用只拒绝新订购；停用瞬间已有有效订购链接/窗保持至自身结束条件，
历史链接行与历史卫星全部保留可查，禁止物理删除。**

- 同源状态机：停用态唯一来源 = `卫星_套餐属性` 当前版 `属性.状态=='停用'`，
  套餐开版/停用、订购写闸、贯验、只读接口共用同一读取函数。
- 失败闭并发：停用与装载写事务均 `BEGIN IMMEDIATE`（连接配 `busy_timeout`），
  单写者队列串行、拿锁后复检；停用未提交/回滚则闸内看不到停用，有效态不分叉；
  停用先提交则排队的新链事务复检必拒，杜绝「卫星已停用、新链仍落入」半截。
- 停用单调：已停用套餐禁止经通用装载复活，重复停用幂等跳过。
- 接口：
  - `POST /api/套餐/停用`（体：`套餐业务键/装载日/原因`）
  - `GET /api/套餐/下架贯验?套餐业务键=…`（只读：停用态、新链拒绝位、旧链/窗有效态、违例、历史保留数）
- 全仓贯验新增检项「停用后无新链」，依据链接 `入库时刻` 与卫星 `停用时刻`（微秒精度）独立举证。
- 测试：`backend/tests/test_套餐下架断链.py`（含并发交错两向、回滚不分叉、同批桥接拦截）。
