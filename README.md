# 号枢

中文名：**号枢** · 前缀 `haoshu` · 端口 **6300 / 11300**

## 骨架

**业务键入枢纽 → 关系进链接 → 属性进卫星（载荷哈希开版）→ 枢纽-链接-卫星互证**

皮：号卡 / 套餐 / 客户。去皮是 Data Vault，不是营业厅办号、不是积分商城。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6300 → 入湖灌样例 → 枢纽/链接/卫星 → 贯验
```

## 套餐下架断链（已落地，口径甲：断链清单+可订购角标为挡新订购权威）

全局唯一口径：**停用只拒绝新订购；停用瞬间已有有效订购链接/窗保持至自身结束条件，
历史链接行与历史卫星全部保留可查，禁止物理删除。**

### 关键设计取舍（全局只贯彻一种：甲）

| 人为分叉状态 | 甲（本实现，权威=断链清单+可订购角标） | 乙（未采用，权威=卫星停用字段现场） |
| --- | --- | --- |
| 正常停用（三源齐备） | 写闸拒绝 | 写闸拒绝 |
| 只拨可订购标志为不可订购（卫星在用、清单无记） | **写闸拒绝**（依标志），贯验判分叉 | 写闸放行，贯验失败 |
| 只改断链清单记 retired（卫星在用） | **写闸拒绝**（依清单），贯验判分叉 | 写闸放行，贯验失败 |
| 卫星已停用但清单缺行/标志未熄 | 写闸拒绝（卫星源命中），贯验判「回执成功而清单空」 | 写闸拒绝，贯验失败 |

- **同票收口**：停用事务（`BEGIN IMMEDIATE` 单写者）内按序写
  停用卫星新版 → 断链清单投影（套餐业务键、停用卫星哈希、闭链摘要、时刻）
  → 熄灭可订购角标；提交前三源复检，任一缺失或哈希分叉即抛错整票回滚到停用前。
  禁止停用回执成功而清单空，禁止标志与停用卫星分叉。
- **失败闭并发**：停用与装载写事务均 `BEGIN IMMEDIATE`（连接配 `busy_timeout`），
  单写者队列串行、拿锁后复检；停用先提交则排队的新链事务复检必拒，
  杜绝「停用卫星已落、新链哈希也进正式」半截，正式新链增量必须为零。
- **写闸**：`订购写闸` 同时读 断链清单 / 可订购角标 / 卫星停用态，任一源指停用即拒；
  拒因回送命中的具体凭据，甲/乙行为在测试中显式可区分。
- **停用单调**：已停用套餐禁止经通用装载复活，重复停用幂等跳过（回送三源互证状态）。
- **贯验**：全仓贯验新增检项「断链投影三源互证」，与既有「停用后无新链」并列，
  三源（卫星现场 ↔ 清单 ↔ 角标）任一分叉即判败。
- 接口：
  - `POST /api/套餐/停用`（体：`套餐业务键/装载日/原因`，回执含停用卫星哈希与闭链摘要）
  - `GET /api/套餐/下架贯验?套餐业务键=…`（只读：停用态、新链拒绝位、清单/角标、三源互证、旧链/窗、违例、历史保留数）
  - `GET /api/套餐/断链清单核证?套餐业务键=…`（**基线所无的新增只读接口**：清单逐行回证三源一致性，省略套餐键则列全量）
  - `GET /api/贯验/可订购角标`（角标+清单投影+互证违例）
- 测试：
  - `backend/tests/test_套餐下架断链.py`（含并发交错两向、回滚不分叉、同批桥接拦截）
  - `backend/tests/test_断链清单同票收口.py`（同票收口、只拨标志/只改清单的甲拒绝与甲乙区分、
    事务故障整票回滚、核证只读接口、并发零增量）
